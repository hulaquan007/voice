# 变声器（Android）

男声变女声、甜妹、熟女、御姐、萝莉、大叔等音效，实时变声 + 录音分享。

## 运行
1. 安装 Android Studio（Koala 或更新版本），用 **Open** 打开本目录 `VoiceChanger`
2. 等待 Gradle 同步完成（首次会自动下载依赖）
3. 手机开启 USB 调试，点 Run ▶ 安装；首次启动授予麦克风权限

## 使用
- 选音效（甜妹 / 熟女 / 男变女…），用滑块再微调音高
- 点「开始变声」，对着麦克风说话，声音会实时变声播放
- 「录制」可把变声后的声音存成 WAV，再「试听」或「分享」给微信/QQ 等

## 关于「和任何人讲话」
Android 不允许普通应用直接改写电话/微信通话的音频，所以有这几种用法：
- **发语音文件**：录制 → 分享到聊天软件（以文件形式发送）
- **面对面/外放**：戴耳机自己听，或开外放让对方听（外放贴近对方手机的麦克风也可以）
- **游戏/直播/电脑语音**：用蓝牙、USB 或 3.5mm 线把手机的声音输出接到电脑，作为电脑的麦克风输入

## 调音
音效参数在 `VoicePreset.kt`：
- `semitones` 升降调（男变女一般 +4 ~ +8）
- `brightness` 高频亮度、`warmth` 低频厚度、`breath` 气声

## 技术说明
采样率 44.1kHz 单声道；变调用双抽头延迟线（约 20~40ms 延迟）；音色用一阶滤波 EQ；输出带软限幅防爆音。

请仅用于娱乐、直播、游戏等正当场景，不要冒充他人或用于欺骗。
